# Этапные выпуски ComponentPress

Каждый завершённый этап публикует один автономный Windows x64 файл:

```text
releases/0.NN/ComponentPress-0.NN-win-x64.exe
```

`NN` — двузначный номер этапа от `01` до `16`. Выпуск запускается без Python, виртуального окружения, скриптов и других файлов дистрибутива. Версия выпуска приложения не связана с версией игрового проекта или `schema_version`.

Исправляющий выпуск сохраняет номер этапа и добавляет patch, например `releases/0.14.1/ComponentPress-0.14.1-win-x64.exe`; формат проекта остаётся прежним.

После успешной сборки каждого нового релиза в `releases/0.NN/CHANGES.txt` добавляется русскоязычный текст UTF-8: версия, дата, фактические изменения относительно предыдущего выпуска (для первого — исходные возможности), исправления, известные ограничения и существенные несовместимости при наличии. Документ не требуется для запуска `.exe`. Для релизов, собранных после введения правила, выпуск без `CHANGES.txt` не завершён. Уже опубликованные релизы не дополняются задним числом; правило действует и для будущих ретроспективных сборок `0.01`–`0.02`.

Перед публикацией фиксируются smoke-проверка на Windows 10 x64 и SHA-256 файла. Старые выпуски не перезаписываются.
