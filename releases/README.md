# Этапные выпуски ComponentPress

Каждый завершённый этап публикует один автономный Windows x64 файл:

```text
releases/0.0N/ComponentPress-0.0N-win-x64.exe
```

`N` — номер этапа от 1 до 9. Выпуск запускается без Python, виртуального окружения, скриптов и других файлов дистрибутива. Версия выпуска приложения не связана с версией игрового проекта или `schema_version`.

Перед публикацией фиксируются smoke-проверка на Windows 10 x64 и SHA-256 файла. Старые выпуски не перезаписываются.
