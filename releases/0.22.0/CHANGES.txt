ComponentPress 0.22.0

- Ключи изображений schema 9 больше не задают ширину и высоту. Высота изображения в тексте соответствует размеру шрифта, пропорции сохраняются. Новый ключ предлагается из имени файла без расширения; в менеджере ключей основное имя видно сразу, дополнительные старые псевдонимы можно раскрыть и отредактировать.
- Проекты schema 8 автоматически преобразуются в schema 9 при открытии. Миграция работает без резервной копии, может продолжиться после сбоя и заранее проверяет, что зарегистрирована полная цепочка версий. Каждый переход вынесен в собственный модуль общего каталога миграций.
- Неизвестные ключи в тексте из Excel не прерывают проверку: ключ остаётся текстом, а предупреждение с координатой ячейки появляется в событиях.
- Добавление изображений и ключей автоматически запускает проверку и обновляет превью, не закрывая его. В форме нового изображения поля файла и Excel-столбца показываются по выбранному источнику.
- Список шрифтов показывает семейства их гарнитурой. Поля координат и размеров отображают целые значения без кнопок изменения шага, сохраняя ввод дробей.
- На холсте появились миллиметровые линейки с маркерами положения курсора. В строке состояния путь проекта занимает до четверти ширины, последнее событие использует оставшееся место.
- На Windows временные архивы PNG удаляются после закрытия файлов; публикация ZIP на другом томе выполняется через отдельный временный файл.

Формат архива проекта остаётся версии 1; build-report — версии 3.
