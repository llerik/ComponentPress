# ComponentPress

ComponentPress — настольный редактор печатных компонентов настольных игр. Он связывает макеты с данными Excel и экспортирует компоненты в PNG и PDF с линиями реза. Перед сборкой можно проверить глобальные параметры печати и область результата; прогресс показывает текущие компоненты, а завершение может открыть PDF или папку результата. Проекты и их версии можно сохранять и восстанавливать; редактор включает офлайн-справку, список недавних проектов, переключение Prod/Test и фильтрацию событий.

Основные технологии: Python 3.14, PySide6, openpyxl, ruamel.yaml, Pydantic и Jinja2. Исходники рассчитаны на Windows 10 x64 (1809+) и поддерживают запуск на macOS и Linux. Автономный дистрибутив собирается для Windows; сборки для macOS и Linux не предоставляются.

## Запуск на Windows

Установите Python 3.14 с командой `py -3.14`. В PowerShell из корня репозитория выполните:

```powershell
.\project.cmd setup
.\project.cmd run
```

Команда `setup` создаёт виртуальное окружение и устанавливает закреплённые зависимости. Для запуска CLI используйте `project.cmd cli`; например, проверить демонстрационный проект можно так:

```powershell
.\project.cmd cli validate .\examples\demo-game
```

## macOS и Linux

Установите Python 3.14, затем из корня репозитория выполните `make run`. Makefile создаст виртуальное окружение и установит приложение. Автономные дистрибутивы для этих систем пока не собираются.

## Проверки и сборка

Полный набор тестов запускается двумя командами из корня репозитория в PowerShell. UI-тесты должны выполняться последовательно:

```powershell
$env:QT_SCALE_FACTOR='0.8'; .\.venv\Scripts\python.exe -B -m pytest -n auto -m "not ui"
$env:QT_SCALE_FACTOR='0.8'; .\.venv\Scripts\python.exe -B -m pytest -n 0 -m ui
```

Подробные параметры запуска описаны в `docs/09-parallel-tests.md`. Windows-дистрибутив собирается командой `.\project.cmd release`; версия приложения задаётся в `src/componentpress/version.py`. Конкретные изменения и ограничения выпуска описываются в его `releases/<версия>/CHANGES.txt`. Готовый EXE создаётся локально и не входит в Git.

## Формат проекта и примеры

Папка игры должна содержать YAML-файл `project.cpress`. Если YAML компонента не проходит проверку или использует другую версию схемы, проект всё равно открывается: компонент доступен в текстовом режиме, ошибочный текст можно сохранить и исправить; макет и сборка станут доступны после исправления. Openpyxl не пересчитывает формулы Excel: пересчитайте книгу в Excel или совместимом редакторе и сохраните её перед использованием. Демонстрационные проекты находятся в `examples/`.

Основной код находится в `src/componentpress/`, тесты — в `tests/`, закреплённые зависимости Windows — в `requirements/`, сценарии упаковки — в `packaging/`, описания выпусков — в `releases/`.

В настроенной рабочей среде технические документы и правила агентов доступны в `docs/` и `AGENTS.md`. Они хранятся в отдельном репозитории `ComponentPressAgent` и не входят в обычный клон репозитория приложения.
